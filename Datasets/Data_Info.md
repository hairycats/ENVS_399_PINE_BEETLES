# Data sets used in the white paper
While not all of the figures made from these data sets made it into the paper, at least one figure created from each of these datasets is refrecened within the final product.

**Dataset1_100x100.csv** and **Dataset2_500x500.csv** - These are the SK, Canada datasets. They were not used much in the analysis and only refrenced when we were talking about prospective solutions. 

**beetles_with_climate.csv** - The dataset that was used for the bulk of our analysis it is a combination of the FEM data and the PRISM data that is detailed in the README

# Data sets not used in the white paper
These datasets were used to create some of the visuals that we chose not to include in the white paper. 

**mpb_reconstruction_data.csv** - A historical data set used to create the first visual in <code>Visualizations.Rmd</code>, it did not have the desired variables to be useful in our analysis

**FEM_Data.csv** - This is the same as the <code>beetles_with_climate.csv</code> data before the climate variables were changed to comething human interreptable.
